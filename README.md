# Laboratorio de seguridad web

Práctica de pruebas de seguridad sobre OWASP Juice Shop, un aplicativo vulnerable a propósito que corre solo en `127.0.0.1`.

## Objetivo
Documentar el proceso completo de cada vulnerabilidad: observación, hipótesis, prueba controlada, evidencia, impacto, corrección y verificación.

## Herramientas
- Docker (imagen oficial `bkimminich/juice-shop`)
- Herramientas de desarrollo del navegador (red y DOM)

## Ejercicios
Ver `notas-juice-shop.md`. Cada ejercicio indica su estado real; no se marca como completado algo que no se haya verificado.

## Reglas
- Solo laboratorio local y datos ficticios.
- Ningún payload se usa contra sistemas que no sean del laboratorio.
